## Descripción General

Plataforma web adaptativa de aprendizaje para educación secundaria (grados 6° a 11°) impulsada por la **API de Google Gemini**. El sistema permite generar lecciones teóricas, calificar evaluaciones interactivas en tiempo real y ofrecer una **tutoría de refuerzo personalizada** enfocada exclusivamente en los conceptos reprobados o fallados por el estudiante.

---

## Stack Tecnológico

* **Frontend:** HTML5, CSS3 (Tailwind CSS), JavaScript
* **Backend:** Python con FastAPI (API REST)
* **Base de Datos:** PostgreSQL en Supabase
* **Servicio de IA:** Google Gemini API (Modelo Gemini 1.5 Flash mediante SDK en Python)
